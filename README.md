# Ignite Projects

Crie uma landing page/página de vendas premium, moderna e extremamente profissional para um produto digital chamado “Primeiro Projeto Online”.

OBJETIVO:

A página deve converter visitantes em compradores. O produto ensina iniciantes, especialmente jovens, a desenvolver habilidades digitais e criar seus primeiros projetos online usando ferramentas acessíveis e inteligência artificial.

IMPORTANTE:

Não faça promessas de enriquecimento rápido, renda garantida ou resultados financeiros garantidos.

Não use depoimentos falsos, números falsos ou escassez falsa.

A comunicação deve ser persuasiva, mas honesta.

PÚBLICO:

Jovens iniciantes que querem aprender a usar internet, IA e habilidades digitais para criar projetos e buscar suas primeiras oportunidades online.

Eles não sabem por onde começar e estão cansados de conteúdos complicados e genéricos.

ESTILO VISUAL:

- Design premium e moderno

- Visual inspirado em startups de tecnologia

- Fundo escuro elegante

- Cards com efeito glassmorphism

- Gradientes sutis

- Tipografia moderna e grande

- Bordas arredondadas

- Microanimações suaves

- Muito espaço em branco

- Aparência profissional, não infantil

- Responsivo para computador, tablet e celular

- Excelente contraste e acessibilidade

- Botões chamativos e claros

- Não exagerar nas animações

CORES:

Use principalmente preto/grafite, branco e tons de azul/roxo.

Use a cor de destaque apenas para CTAs e elementos importantes.

INSTRUÇÕES DE UX/UI:

- Todos os botões devem funcionar.

- Os CTAs devem levar para uma seção/configuração de checkout facilmente substituível.

- Criar navegação suave entre as seções.

- Adicionar animações de entrada discretas.

- Criar hover states nos cards e botões.

- Layout perfeitamente responsivo.

- No mobile, manter o CTA facilmente acessível.

- Otimizar carregamento.

- Usar componentes reutilizáveis.

- Código organizado.

- SEO básico configurado.

- Criar favicon/logo simples relacionado ao conceito de projeto digital.

- Não utilizar imagens genéricas de pessoas sorrindo em escritório.

- Prefira elementos gráficos, dashboards, mockups e ilustrações digitais.

COPYWRITING:

A comunicação deve ser direta, jovem, confiante e profissional.

Evite frases clichês como:

“Fique rico”

“Ganhe milhares de reais”

“Segredo dos milionários”

“Fórmula garantida”

Use frases focadas em:

- começar

- aprender

- executar

- construir

- desenvolver habilidades

- criar projetos

- usar IA de forma prática

A página deve parecer um produto digital real e premium, não uma página genérica criada por IA.
